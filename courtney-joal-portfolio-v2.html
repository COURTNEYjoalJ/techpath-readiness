TechPathReady

I built TechPathReady to bring role-based roadmaps, skill assessments and browser-saved readiness reports into one experience.

HTML · CSS · JavaScript · localStorage

Explore project details

What I built

I built a static HTML, CSS and JavaScript learning platform with career roadmaps, skill quizzes and readiness reporting.

Assessment workflow

Learners choose a country and role, explore weighted skills and required topics, then complete topic-based tests. Answers are shuffled, and full test completion is required before scores are saved.

Results and learning

I added browser-local saved scores, a readiness dashboard, standalone practice quizzes and learning pages for Python, JavaScript, SQL, HTML, CSS and Java. The platform includes five scored career paths and a separate GCSE Maths and Python support path.

Engineering choices

I used localStorage for browser-local persistence and separated question banks, career data, scoring and presentation. Beta enquiries and feedback use external forms.
